Met performancing firefox op je Drupal site posten.

Ik schrijf dit stukje met een nieuwe tool: performancing voor Firefox. Nu gebruik ik FF niet als mijn dagelijkse browser, dus zal ik deze extensie ook niet vaak gan gebruiken. Ik wilde enkel eens zien waar die hype over deze tool vandaan komt.

Het hieeft hier en daar nog wat ruwe randjes, dat is jammer. Zo kun je bijvoorbeeld niet een RUL uit je pagina of adresbalk copieren nadat je op he link-knopje klikte.

Uiteraard werkt deze tool perfect met Drupal, anders kon je dit niet lezen, hé :)

Eerst moet je in je drupal site de blogapi module inschakelen en configureren onder http://example.com/admin/settings/blogapi. Meer over de blogapi module vindt je op Drupal.org. Merk ook op dat voor een poersoonlike weblog, je het beste stories kunt nemen!

Voor Drupal kies je in de account wizard, de optie Custom Blog. Dan de optie Drupal.  En onder Server API URL vul je in: http://myserver.com/xmlrpc.php. Vervolgens de gegevens van je account (nogmaals, it soort dingen als SuperUser doen is erg onverstandig!) En viola, performancing is klaar om gebruikt te worden.
