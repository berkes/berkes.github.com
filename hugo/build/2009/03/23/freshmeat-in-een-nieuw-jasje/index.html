freshmeat in een nieuw jasje

[!["They only call them pigs when they're al...](http://farm1.static.flickr.com/156/434733216_cb393da74d_m.jpg)](http://www.flickr.com/photos/32182083@N00/434733216) Image by [Charles DH Crosbie](http://www.flickr.com/photos/32182083@N00/434733216) via Flickr
[Freshmeat](http://freshmeat.net/) een van de grootste portals voor [Unix](http://en.wikipedia.org/wiki/Unix "Unix") en andere Crossplatform Software heeft een nieuw jasje. Werd tijd. Freshmeat is eigenlijk altijd mijn beginpunt bij het zoeken naar software voor Windows (Op Linux gebruik ik gewoon mijn package-manager, natuurlijk). Want je vind hier vooral erg veel goede OpenSource. En veel gegevens waarmee de kwaliteit en geschiktheid van een stuk software goed is af te lezen.
