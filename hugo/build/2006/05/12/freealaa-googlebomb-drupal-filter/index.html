Freealaa googlebomb Drupal filter.

This is my small addition to the bloggers rally against the arrest of Alaa. It is a small Drupal filter that will turn every occurence of Egypt into <a href="http://freealaa.blogspot.com/"> Egypt </a>Grab it here. Rename it to alaa_egypt_filter.module. And install it on your website. Note that you must enable the filter under "input" formats. Also note that this filter is only tested on a 4.6 website, but that it should also work on a 4.7.
