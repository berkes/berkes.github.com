# Archive

Historical documents from the Jekyll → Hugo migration (2026, issues
#138–#145). Kept for reference and archaeology only: they describe the
migration as it happened, not the current setup. See the top-level
README.md for how the site is operated today.

- `migration-jekyll-inventory.md` — the Jekyll site inventory and the
  migration requirements the port was verified against.
- `migration-hugo-notes.md` — working notes and decisions of the port.
- `url-parity-baseline.txt` — the frozen URL list the Hugo build had to
  match before cutover (parity was proven: 0 missing, 0 new, 0 broken).
